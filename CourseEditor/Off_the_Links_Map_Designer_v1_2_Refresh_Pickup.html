Print layout

Each portrait page is 11.25″ × 15.5″. Switching to one page removes the right page’s contents; Undo restores them. Two pages join along the dashed seam; the hex grid continues across it. Hexes measure ½″ (12.7 mm) across flats. Only complete hexes inside the page margins are editable. PDF and SVG export at actual size; PNG exports at 300 pixels per inch.

How to use

Choose a terrain brush, then click or drag across hexes. Use the special tools to place the hole and three tee positions. Undo and redo terrain changes. Export JSON for future integration with the main prototype, or a PDF for printing at Actual Size / 100%.

Accessibility: Sand traps are golden with three dark dots and −3; Heavy Rough is dark green with grass marks and −2; normal Rough shows −1; trees are blue-green with a white tree symbol, so they remain distinguishable without color perception.

Note: This is a standalone editor. JSON export uses the main prototype's axial q/r coordinates and terrain names, and includes print-layout metadata.
